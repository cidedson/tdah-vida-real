# Segurança e privacidade

O app guarda tudo no celular de quem usa e não tem servidor. Mesmo assim, se você achar uma falha que exponha dados, chaves de API ou permita instalar um APK falso por cima do app:

1. **Não abra uma issue pública.**
2. Use a aba **Security › Report a vulnerability** deste repositório (relato privado do GitHub).
3. Conte o que encontrou, a versão do app e, se puder, como repetir.

Respondo assim que puder. Obrigado por cuidar de quem usa o app.
